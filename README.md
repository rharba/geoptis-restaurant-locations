# Geoptis - Restaurant Locations

Application web de gestion, recherche et visualisation de restaurants et de leurs coordonnées géographiques.

Projet réalisé dans le cadre du test technique Full-Stack Geoptis.

## Fonctionnalités

- Ajouter un restaurant
- Afficher la liste des restaurants
- Rechercher par nom ou adresse
- Filtrer par type de cuisine
- Modifier un restaurant
- Valider les coordonnées géographiques
- Afficher les restaurants sur une carte interactive
- Calculer la distance entre l'utilisateur et les restaurants
- Ouvrir un itinéraire Google Maps depuis une adresse
